# Vehicle Service Management System

A beginner-friendly vehicle service management application built with **Python, Streamlit and SQLite**.

## Features

- Add and manage customers
- Register vehicles against customers
- Record vehicle service visits
- Store service type, date, cost and notes
- View service history
- Local SQLite database for persistent storage

## Tech Stack

- Python
- Streamlit
- SQLite
- SQL

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The application creates `vehicle_service.db` automatically when it starts.

## What I learned

This project helped me practise relational database design, SQL operations, Python application logic and connecting a user interface to a database.
